Simultaneous Up + Down

The important part of this configuration is that Y and A are independent buttons.

Y = Move Up
A = Move Down

Y + A = Move Up + Move Down simultaneously

This allows an Xbox controller to perform techniques that require simultaneous opposing directions.

JoyToKey Configuration

JoyToKey is used to provide an additional Down input while preserving normal joystick movement.

Why JoyToKey?

MMR's native controller bindings provide one gamepad input for each action. JoyToKey allows an additional keyboard input to be generated from the Xbox controller.

Current JoyToKey Down Settings

The Down assignment uses JoyToKey's analog input level feature so that a more deliberate downward stick movement is required.

Input 1 = None
Input 2 = NumPad5
Input 3 = None

Thresholds = 50% / 100%

About This Guide

This configuration was developed and tested specifically for an Xbox controller with MMR. The settings may need adjustment for different controllers or play styles.
