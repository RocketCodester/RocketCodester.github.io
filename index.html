Lode Runner: Mad Monks' Revenge

Xbox Controller & JoyToKey Guide for Quirks Mode

About This Guide

This is a community-created Xbox controller configuration for Lode Runner: The Mad Monks' Revenge Definitive Edition. The goal is to make MMR's classic movement quirks easier to perform with an Xbox controller while preserving comfortable joystick movement.

Important: This is a community-created configuration. It is not an official Quark Robot controller configuration.

MMR's official documentation explains that Quirks Mode preserves most of the known bugs from the original Lode Runner Online: The Mad Monks' Revenge.

Official MMR documentation: Quirks Mode

Xbox Controller Mapping

The core of this configuration is using separate Xbox buttons for UP and DOWN. This makes it possible to press both directions simultaneously.

MMR Action Xbox Input
Move Up Y
Move Down A
Move Left Left Stick ←
Move Right Left Stick →
Move Down (additional input) Left Stick ↓ → JoyToKey → NumPad5
Shoot Left LT
Shoot Right RT
Pickup Tool LB
Use Tool RB

Movement Layout

Y = UP

Left Stick ← = LEFT     Left Stick → = RIGHT

A = DOWN
Simultaneous input:

Y + A = UP + DOWN simultaneously

Walking Through Floors

One reason this controller configuration is useful is MMR's Walking through floors quirk.

The official MMR documentation says that this works when you are on a ladder with bedrock below. Hold UP while rapidly tapping DOWN many times. If DOWN is tapped quickly enough, the player can sink through the floor and enter the room below.

The official documentation credits Dan Bank with discovering this quirk.

Source: MMR — Quirks Mode: Walking through floors

Xbox Controller Method

Y = UP
A = DOWN

Hold Y + rapidly tap A

Because Y and A are independent Xbox controller buttons, they can be pressed simultaneously. This makes the UP + DOWN input needed for the Walking Through Floors quirk much easier to perform.

Why JoyToKey Is Used

MMR's native gamepad configuration assigns a single gamepad binding to each action. JoyToKey provides an additional input path by converting a controller input into a keyboard key.

Xbox Left Stick ↓
↓
JoyToKey
↓
Keyboard NumPad5
↓
MMR Move Down

This gives the controller two independent ways to perform DOWN:

Xbox A → MMR Move Down
Left Stick ↓ → JoyToKey → NumPad5 → MMR Move Down

The joystick can therefore remain available for normal movement while the A button provides the deliberate DOWN input needed for simultaneous UP + DOWN.

JoyToKey Down Configuration

A simple direct mapping of Left Stick ↓ to NumPad5 caused an undesirable delay when changing from descending a ladder to moving left or right.

A more selective analog-input configuration produced a much better result.

Stick1: ↓

Input 1 = None
Input 2 = NumPad5
Input 3 = None

Thresholds = 50% / 100%

This makes a more deliberate downward stick movement necessary before JoyToKey generates the virtual DOWN key.

This configuration substantially reduces the ladder-transition problem caused by a continuously active virtual DOWN input.

JoyToKey Profile

The JoyToKey configuration should be kept in an MMR-specific profile so that the virtual NumPad5 input does not affect Windows or other games.

Recommended profile name:

MMR - Lode Runner

Associate the profile with the MMR executable so JoyToKey automatically uses these mappings while MMR is running.

MMR Configuration

MMR stores keyboard and gamepad bindings in its CONFIG.XML configuration file. The official documentation explains that the configuration file stores keyboard and gamepad bindings and that the gamepad dead-zone threshold applies to the thumb sticks.

Official configuration documentation: MMR Configuration File

Important Distinction

The Walking Through Floors behavior itself is an officially documented MMR quirk. The Xbox + JoyToKey mapping described on this page is a community-created controller solution for making the required UP + DOWN input easier to perform.

The official MMR documentation credits the discovery of Walking Through Floors to Dan Bank.
